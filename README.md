# 小宇宙 · 品牌概念介绍网站

中文播客品牌概念页面，包含夕阳海岸首屏、玻璃播放器、时间戳评论、兴趣探索与官方客户端下载入口。

本项目为非官方概念设计，与小宇宙官方无隶属关系。评论与声音为演示内容。场景根据用户提供的视觉参考编辑制作。

## 预览

直接打开 index.html，或运行：

```sh
python3 -m http.server 8080
```

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch，选择 main 分支、根目录，保存即可。

项目为纯静态 HTML/CSS/JavaScript，无需构建，无需密钥。支持移动端和减少动态模式；音频仅在主动点击后播放。
